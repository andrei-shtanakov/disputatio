# disputatio

Headless-оркестратор, гоняющий цикл «автор ↔ ревьюер» над рабочим
git-репозиторием. Два агента ведутся через CLI-адаптеры и **никогда не
разговаривают друг с другом**: единственный посредник — оркестратор, а всё
общение идёт артефактами фиксированной схемы на диске.

## Что здесь есть

| Команда | Что делает |
|---|---|
| `disp run` / `disp resume` | одна сессия debate loop'а над кодовой задачей (SPEC-001) |
| `disp pipeline run` / `resume` / `status` / `export` | пайплайн полировки документов: пара «спека + план» либо одиночный документ (SPEC-002) |

Вид пайплайна выводится из формы секции `[pipeline]` конфига, отдельной
подкоманды у него нет.

## Документация

- `disputatio-SPEC-001-round-protocol.md` — протокол раунда, FSM сессии,
  схемы артефактов, анти-галлюцинационные правила.
- `disputatio-SPEC-002-doc-pipeline.md` — пайплайны полировки документов:
  виды, контуры, манифест, doc-гейты, resume и экспорт.
- [docs/document-pipeline.md](docs/document-pipeline.md) — сквозной пример
  вида `document`: конфиг, запуск, состав `result/`, что делает человек
  дальше.
- `docs/workstream-setup.md` — раскладка workstream'ов разработки.
